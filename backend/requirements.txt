# NOT the file Vercel installs from. That is ../requirements.txt, at the

# This header used to claim the opposite, and it cost a production outage:
# Pillow was added here for the payment-proof image analysis and not to the
# root file, so on Vercel `from PIL import Image` raised at import, app.main

# /api/health included, which made a missing package look like an auth or
# environment fault.
#
# So: anything imported at runtime must be named in BOTH files, even if it
# arrives locally as somebody else's transitive dependency. email-validator
# did exactly that once, so EmailStr worked on this machine and the
# serverless function crashed on import. Keep the two lists in step.
